## ⚙️ Cara Instalasi & Menjalankan Proyek

Ikuti langkah-langkah di bawah ini untuk menjalankan aplikasi ini di komputer Anda:

### 1. Prasyarat
* Pastikan **Node.js** sudah terinstal di laptop Anda.
* Pastikan HP Android Anda sudah mengaktifkan **Opsi Pengembang** dan **USB Debugging**, serta terhubung ke laptop via kabel USB.

### 2. Kloning Repositori & Instal Dependensi
Buka terminal di folder proyek Anda, lalu jalankan perintah berikut untuk mengunduh modul yang diperlukan:
```bash
git clone [https://github.com/username/nama-repo-anda.git](https://github.com/username/nama-repo-anda.git)
cd nama-repo-anda
npm install
```

### 3. Jalankan Aplikasi Melalui Terminal
jalankan perintah ini di terminal  folder proyek.
```bash
npm start
